# Contributing

Thank you for helping. Bug reports, ideas, translations and code are all welcome.

- **Bugs and ideas**: open an issue. Never include real archive material or anyone's personal data.
- **Security problems**: do not open an issue; see [SECURITY.md](SECURITY.md).
- **Code**: read [docs/development.md](docs/development.md) first. Open a pull request against `main`; CI must pass.
  New UI text needs its German translation, and the "Languages" rules in [docs/roadmap.md](docs/roadmap.md) apply.
